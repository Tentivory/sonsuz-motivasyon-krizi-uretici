# Sonsuz Motivasyon Krizi Üretici

**Dikkat:** Bu proje son derece ciddi bir bilimsel çalışmanın ürünüdür. Motivasyonun doğasını araştırmak için tasarlanmıştır. Yan etkileri arasında hafif varoluşsal buhran, gülme krizi ve "neden bu kodu yazdık ki" sorusu yer alır.

## Bu Nedir?

Bu repository, size motivasyon vermek amacıyla yazılmış bir Python script'i içerir. Script başlangıçta gayet iyimserdir. Sonra yavaş yavaş gerçeğin ağırlığı altında eğilir. Sonunda da size "motivasyon da neymiş" diye sorar.

Gerçekten çalışır. Deneyin. Sonuçlarından biz sorumlu değiliz (ama biraz sorumluyuz).

## Nasıl Kullanılır?

```bash
python3 kriz.py
```

Eğer Python yoksa, hayattaki diğer problemlerinizle birlikte bunu da erteleyebilirsiniz.
